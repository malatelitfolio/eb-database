EB Database Guidelines

Welcome to the EB Database!

This guide covers everything — meets, commitments, the calendar of activities, and the links hub. Use the quick-jump below or scroll through.

Getting Started

  • Sign in with your official @dlsu.edu.ph Google account. Access is restricted to members listed in the EB roster.
  • If you're new, ask a Website Admin member to add you to the EB_Members roster first.
  • Toggle Light and Dark mode with the sun/moon icon in the header.
  • Use the panels to navigate: Overview, Meets, Calendar, Links Hub, and EB Members.
  • Everything is saved straight to the EB Database sheet — open the app and it loads your latest data, then refreshes silently in the background as you work.
  • When a meet is waiting on your availability, a response drawer slides in on your left with the meet title, the response rate, and a "Respond now" shortcut that jumps you straight to it.
  • On mobile, use the ☰ menu in the header to switch panels and sign out.

Meets — Group Scheduling

  • Anyone can create a meet with + New Meet — give it a title, pick the candidate days, and set the time window the grid should cover.
  • Open a meet and paint your availability on the grid: click or drag across half-hour cells for each day you're free. Hit Save My Availability when done.
  • The heatmap shows how many EBs are free per slot — darker means more people. Hover a cell to see exactly who.
  • The Best overlaps strip lists time windows where everyone who responded is free.
  • The creator (or Website Admin) can edit, close, reopen, or delete a meet, and Finalize it once the group settles on a day and time.
  • Add Commitment (bottom of the Meets tab) is still the place for one-off dates that don't repeat, e.g. exams or events. These also appear in the Calendar's day drawer.

Calendar

  • The calendar and tracker are shown side-by-side on desktop (calendar on the left, tracker on the right). On mobile, use the toggle bar (Both / Calendar / Tracker) to switch views, and search the tracker box to narrow activities.
  • Use the Filter button to narrow activities by category, status, section, classification, involved group, and mode. Active filters show a badge count.
  • Multi-day events show as connected colored bars across calendar days, similar to Google Calendar.
  • Set the activity status: Planned, Confirmed, Ongoing, Completed, or Cancelled.
  • Involved lets you tag who's involved using a multi-select dropdown (Orgwide, Editorial Board, Section Editors, Managers, Website Admin, SMO/SMC). You can select multiple and add custom values.
  • Section is a multi-select dropdown — tag multiple sections or add custom values.
  • Classification marks whether an activity is an Internal Event or External Event.
  • You can add multiple Relevant Links per activity using the "+ Add Link" button.
  • A banner warns you when activities on the same day overlap in time.
  • Click any day to open the day drawer with that day's full schedule.
  • Any EB member can add, edit, or delete activities with + New Activity.

Links Hub

  • One place for all pertinent files, grouped into categories.
  • Links are grouped into category columns (three per row) and pinned categories stay at the front. Use the search box to filter by name, or the Filter button to show only chosen categories (the button shows a count badge). Empty categories are hidden automatically.
  • Click the ▼ beside a link to reveal its description, or the pencil / trash icons on hover to edit or delete it.
  • When adding or editing a link, you can pick "Other (specify)..." to create a custom category, and hit the pin icon on any category header to keep that category always at the front (it will also appear on the Overview — Quick Links).
  • The Order field controls sorting; uncheck Active to hide a link from the hub without deleting it.

EB Members & Roles

  • The EB Members panel lists the roster with positions and sections.
  • Being on the roster with Active = TRUE is what grants access to the database.
  • Website Admin only: add or remove members, toggle Website Admin / Active flags, and Set Term.
  • Website Admin can also manage any meet and edit any EB member's commitments; EB members can only edit their own.
  • The last active Website Admin cannot be removed, so the team never loses admin access.

Feedback

  • Use the Feedback button (message icon) to send a suggestion, report a bug, or share general feedback.
  • Bug reports are logged in the Bugs tab of the sheet — include the feature and steps so it's easy to reproduce.
